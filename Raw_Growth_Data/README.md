
### These files contain the comprehensive tree-ring dataset from previous studies conducted before 2012.

> [!TIP]
> Interior Alaska: FB, Bluff_Fairbanks
> 
> Alaska Range treeline: DT, Denali_Treeline, Denali_Treeline (2)
> 
> Alaska Range forest: DF, Denali_Forest, Denali_Forest_2012
> 
> Brooks Range treeline: BT, Brooks_Range_Treeline
> 
> Brooks Range forest: BF, Brooks_Range_Forest
